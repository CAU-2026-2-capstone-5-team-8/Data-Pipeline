# Discovery 검토 신호 42권 후속 점검

2026-10-03에 보존된 canonical 제목과 소개를 대조했다. 이는 **에이전트의 자료 검토**이며 사람의 승인이나 정답 라벨이 아니다. 도서 제외, 추천 후보 변경, precision/recall 계산을 수행하지 않았다. [42권별 관찰과 출처](selection-review-2026-10-03.json)에 ISBN, 기존 검출 위치, 출처 URL·해시 및 에이전트 메모를 남겼다. `human_decision`은 전부 비어 있다.

`9788905058296`은 제목이 확률과 통계인데 수집 소개의 첫 문장이 미적분Ⅰ을 지칭한다. 제공자 자료의 주제 불일치로 기록했고 원문은 수정하지 않았다. 서술 오류인지 상품 연결 오류인지는 확인이 필요하다.

## 구현에 반영한 부분

기존 분야 정규식에는 실제 다른 분야 단어와 시험 관련 단어가 함께 들어 있었다. 감사 v3는 기존 매칭 중 수능·모의고사·기출·고2/고3를 `exam_context_marker`로 분리한다. 발견 범위나 실제 도서 선정 규칙은 바꾸지 않았다.

- 기존 `conflicting_subject_marker` 39권 → 같은 자료에서 분야 관련 신호 1권, 시험 맥락 신호 39권. 법률 책 1권은 양쪽에 포함된다.
- 제목/부제의 `study_aid_marker` 5권은 유지된다.
- 중복을 제외한 검토 대상은 이전과 같은 42권이다.
- 문맥이 필요한 경우 `--include-context`로 일치 전후 최대 80자와 시작 위치를 기록한다. 줄바꿈과 공백을 추가 정리하지 않는다.
- 사람의 판단란은 그대로 비워 두며, 에이전트 관찰은 별도 문서에 둔다.

6분야 v2/v3 보고서의 입력 파일 해시 24개와 검토 대상 ID 집합이 모두 같음을 확인했다. 전체 471권과 원래 목차·문서는 보존됐다. 신호가 없는 책에 대해서는 이번 42권 검토로 적합성을 보장할 수 없다.

## 재현

```sh
uv run data-pipeline audit-selection \
  --data-dir data/experiments/discovery-600-20260929/topics/algorithms \
  --report data/experiments/new-review/algorithms/audit.json \
  --review data/experiments/new-review/algorithms/review.csv \
  --include-context
```

실행한 6분야 문맥 보고서는 로컬 ignored `data/experiments/selection-audit-v3-20261003/<topic>/`에 있다. 기존 v2와 사람 검토 파일을 덮어쓰지 않는다. 에이전트 관찰 JSON은 자동 분류기나 수집/추천 필터로 읽지 않는다.
